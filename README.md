## 🦜 El Pollo Loco

A simple jump-and-run game based on object-oriented approach. Help Pepe to cross the dangerous desert and defeat The Giant Chicken.

* 🎮 Features
* 🕹️ Classic 2D jump-and-run gameplay
* 🎨 Smooth sprite animations using HTML5 Canvas
* 👾 Multiple enemies and an epic end boss
* 🥚 Collectible items and throwable objects
* ❤️ Health, energy, and status bars
* 🧩 Object-oriented game architecture
* ⌨️ Keyboard controls for movement and actions
## 🛠️ Tech Stack
* JavaScript (ES6) – Game logic and object-oriented programming
* HTML5 – Game structure
* CSS3 – Styling and responsive layout
* HTML5 Canvas – Rendering graphics and animations
## 🚀 Getting Started
# Clone the repository
git clone https://github.com/ChristopherHipper/el-pollo-loco.git

# Open the project folder
cd el-pollo-loco

# Start a local server (for example with VS Code Live Server)

Note: Since the project uses JavaScript modules and loads assets locally, it should be run through a local web server instead of opening the index.html file directly.

## 🎯 Controls
| Key | Action |
|------|--------|
| ← / → | Move left / right |
| ↑ | Jump |
| Space | Throw bottle |
## 📂 Project Structure
* index.html – Main HTML file
* style.css – Game styling
* js/ – JavaScript classes and game logic
